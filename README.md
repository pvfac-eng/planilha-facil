# 📊 Planilha Fácil

> Aplicação web leve para criação, gestão, cálculo e exportação de dados estruturados em tabelas diretamente no navegador.

## 📌 Visão Geral

O **Planilha Fácil** foi desenvolvido para resolver a necessidade de manipular e formatar dados tabulares de forma ágil sem a complexidade de softwares pesados ou licenças pagas. A aplicação opera 100% no lado do cliente (Client-side), garantindo privacidade e execução offline após o carregamento inicial.

---

## ✨ Funcionalidades Principais

- **Construtor Dinâmico de Esquemas:** Definição personalizada do nome da tabela e criação de colunas com tipos de dados específicos (Texto, Número e Moeda).
- **Interface de Edição Interativa:** Tabela com suporte a edição direta nas células (`contentEditable`), além de inclusão e remoção rápida de registros.
- **Motor de Cálculo Sem Fórmulas:** Execução de operações matemáticas (Soma, Subtração, Multiplicação e Divisão) entre colunas sem a necessidade de sintaxe complexa de fórmulas.
- **Ordenação Flexível de Dados:** Algoritmo de ordenação crescente (A→Z) e decrescente (Z→A) para qualquer coluna de dados.
- **Exportação Nativa para Excel:** Conversão dos dados em memória para arquivos formato `.xlsx` estruturados, mantendo a integridade dos tipos numéricos.

---

## 🛠️ Tecnologias e Bibliotecas

- **HTML5:** Estruturação semântica da aplicação e modais.
- **CSS3:** Estilização moderna utilizando variáveis CSS, layout fluido com **Flexbox** e **CSS Grid**, e responsividade para dispositivos móveis.
- **JavaScript (Vanilla JS):** Manipulação dinâmica da DOM, controle do estado local da aplicação e lógica de ordenação e cálculo.
- **SheetJS (xlsx):** Processamento e geração do arquivo `.xlsx` direto no cliente.
